# JARVIS Portfolio

A futuristic personal portfolio built with React, TypeScript, Vite, Tailwind CSS, and Framer Motion.

## Setup

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## Notes

- Update the GitHub and LeetCode usernames in `src/data/content.ts`.
- Replace the resume placeholder in `public/resume.pdf` with your real resume.
- The UI is intentionally styled as a Stark-inspired HUD with animated panels and responsive layouts.
